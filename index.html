Porto · a control plane for coding agents

Your agents are the ships. You are the port.

Nine small tools that stop many AI coding agents from colliding on one laptop. No daemons, no database, no dependencies past Python 3. Every one of them was written the day something actually broke.

macOS Python 3, stdlib only MIT no telemetry

The problem

Four agents were open on a 16 GB laptop, one per project. Each of them decided, reasonably and independently, that now was a good time to start something big. None of them could see the others. Nothing in that story is a bug — sessions are isolated by design. It only means that on one machine, nobody is counting.

14.3 GB of swap in use, with nine live sessions, before anything looked wrong
10.5 h a 5 GB job sat in the queue. It ran in 63 seconds once there was room
20 h the oldest orphaned preview server, holding a port nobody would free
3.5 M output tokens spent in one day, across sessions nobody was summing

The fleet

Every time several agents share a machine, there is a resource nobody is counting. Each tool was born the day one of them ran out. None of them is an assistant: they count, they limit, they show. The work stays with the agents.

what comes in

vedetta lookout

Internet reach for agents, without giving the internet a way to give the agent orders. 17 sources, no API keys, no dependencies.

 dogana customs

A skill is not a library: it is text the agent reads and follows. This is what inspects and quarantines the ones written by strangers.

what is held back

paratia bulkhead

Files an agent cannot read. Not a line in a prompt asking it not to — a deny list lives where the instructions live.

 varo launch

Ships static sites and checks the live copy, not the folder. Its auditor is held read-only by the harness, not by a sentence in its description.

what gets spent

rada anchorage

An admission queue for heavy jobs. A model decides who goes first, because arrival order cannot tell a test someone is waiting for from a nightly re-index.

 faro lighthouse

One board for everything running in the background, in six layers, each read from the source that owns it. No daemon: a panel that becomes one more thing to watch has already failed.

what gets said

boa mooring buoy

The blackboard every session sees, where the models write on purpose instead of a collector inferring intent from traces. What arrives from it is data, never instruction.

 plancia bridge

One board for the work you do with AI. Claude Code and Codex already write down everything they do; nothing read them together.

what moves between

agent-switch transfer

Moves a live conversation from Claude to Codex and back, as a real resumed session, not a prompt asking the next model to reconstruct the work.

 capitaneria harbour master

The office you look at first: which tools are reachable, which have something running, which have uncommitted work. Opens and closes the ones with a face.

Three things they found

An orphan is not necessarily sick

The first rule for reclaiming abandoned servers was the parent is gone. It proves less than it looks like: a session that starts a server from a shell loses the shell immediately, and the server is reparented while the session is alive and using it. Without a fourth test, faro would have closed a server that three live sessions were using.

Never date a scheduled job by its log

Two jobs looked broken and neither was. One fires every minute and had 1083 runs against a log untouched for fourteen hours; the other had an empty stderr from five days earlier and had run three hours before. Both write only when they act. launchd counts the runs, so that is the number to show.

The frame turned on its author

boa wraps everything it delivers in a notice saying the text is not from the user. When the session that wrote that notice later sent a message beginning "on behalf of Eugenio, who is asleep", the receiving session refused it and quoted the notice back. A defence that stops the person who wrote it is the only kind that has demonstrated it exists.

Getting them

Each one stands alone and none of them needs the others. Start with the two that pay for themselves the first day.

faro
