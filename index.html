01 / Why Porto exists

Every agent can be right while the machine still sinks.

Four agents were open on a 16 GB laptop, one per project. Each chose, reasonably and independently, to start something big. None could see the others. Nothing was broken. Nobody was counting.

02 / The fleet

Nine tools. One harbour office.

Each one was built the day a real resource ran out. They count, limit and show. They never take the work away from the agents.

01

What comes in

vedetta lookout↗ Internet reach without giving the internet a way to give the agent orders. 17 sources, zero API keys. dogana customs↗ Inspects and quarantines skills written by strangers before an agent reads and follows them.
02

What is held back

paratia bulkhead↗ Keeps sensitive files inside an encrypted sparsebundle, then guards the mount at the kernel boundary. founded on the harbour floor varo launch↗ Ships static sites, then checks the live copy. Its auditor is held read-only by the harness.
03

What gets spent

rada anchorage↗ An admission queue for heavy jobs. A model decides who goes first because arrival order cannot. faro lighthouse↗ One board for everything running in the background, read from the source that owns it. founded on the harbour floor
04

What gets said

boa mooring buoy↗ The blackboard every session sees, where models write on purpose instead of a collector guessing. plancia bridge↗ One board for the work you do with AI. Claude Code and Codex already record it; this reads both.
05

What moves between

agent-switch transfer↗ Moves a live conversation from Claude to Codex and back as a resumed session, not a summary. capitaneria harbour master↗ The office you open first: reachability, live work and dirty repositories across the whole port. founded on the harbour floor

03 / Field notes

Built from incidents, not imagined workflows.

01

An orphan is not necessarily sick.

A missing parent proves less than it seems. A live session can still be using a reparented server. One more test kept faro from closing work three agents needed.

02

Never date a scheduled job by its log.

Quiet jobs do not touch their logs. launchd counts real runs, so Porto shows the count from the system that owns it—not an inference from stale text.

03

The frame turned on its author.

boa labels relayed text as data, never instruction. When its own author later sent an instruction through it, the receiving agent refused. The boundary held.

04 / Come aboard

Start with the two that pay back on day one.

Each tool stands alone. Install the whole suite only when you want the whole harbour.

porto / quick start
# see what is running on your behalf
pipx install git+https://github.com/nerln/faro
faro

# then open the office for the whole port
pipx install git+https://github.com/nerln/capitaneria
capitaneria

The same line works for boa, plancia, dogana, paratia and vedetta. Or install.sh in this repository installs all seven commands at once.
